The hooks folder contains reusable React hooks used to manage frontend logic and application behaviour.

Main hooks

useMapMarkers – Handles map marker-related state and updates.

useThrottledUpdates – Controls frequent updates by throttling them so the UI does not update unnecessarily often.

useWebSocket – Handles WebSocket-related connection and data updates for the frontend.

Purpose: Keep reusable React logic separate from UI components and make the code easier to maintain.
